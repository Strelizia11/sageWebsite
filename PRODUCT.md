# UDD-SAGE

## Platform
Web, responsive public site and private content management dashboard.

## Users and purpose
The official website for Universidad de Dagupan – Scholars’ Association for Greater Excellence. Visitors read organization information, news, schedules, results, activities and public member/leadership directories. Authorized administrators manage this information through Supabase-backed editors.

## Confirmed brand commitments
Use the supplied organization seal unchanged. The user requested a professional visual identity inspired by that logo and appropriate to a scholars organization. The user rejected the previously illustrated Ghibli-inspired direction.

## Content constraints
Do not invent official people, dates, examination results, contact information, organizational history, achievements or metrics. Public content must come from the existing publication workflows. Examinations occur outside this website.

## Technology
Existing Next.js App Router, React, TypeScript, native CSS, Lucide icons and Supabase. Preserve routing, authentication, authorization and publishing behavior during visual changes.
