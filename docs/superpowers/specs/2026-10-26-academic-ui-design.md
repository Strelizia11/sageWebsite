# Professional academic redesign

Date: 2026-10-26
Direction: User requested a professional scholars-organization identity inspired by the existing seal, replacing the illustrated style.

## Intent and implementation
Use the unchanged seal as the principal visual asset. Deep navy, white, restrained gold, precise sans-serif headings, structured spacing and quiet borders establish an academic identity. The homepage leads with the organization introduction and direct access to examinations; lists and directories remain task-focused. Remove the landscape, atmospheric motion and its controls from the active website. Retain keyboard navigation, reduced-motion safeguards, mobile behavior, content workflows and authorization.

## Plan
1. Replace storybook styling with an academic brand stylesheet; remove the scene component from the homepage.
2. Build a navy introduction paired with a formal white seal panel. Refine shared headings, content surfaces, empty states, footer and admin controls.
3. Replace obsolete scenery tests with responsive identity and examination-link coverage.
4. Inspect desktop/mobile, run unit tests, TypeScript, build and Edge tests, and request independent review.

## Constraints
Keep the actual logo, official organization name, current data and routes. No fabricated achievements, people, statistics, or campus photography. No new dependencies. Preserve generated artwork as inactive files rather than destroying it.
